## 交互内容

1. 弹窗右下角有取消和提交两个按钮
2. 点击取消直接关闭弹窗,点击提交按钮调用『资源创建』接口, 成功后触发`props.onFinish`事件然后关闭弹窗
3. 每次关闭弹窗都需要清除表单数据

## 表单字段

| 字段名称       | name | 是否必填 | 类型     | 备注                                                         |
| -------------- | ---- | -------- | -------- | ------------------------------------------------------------ |
| 资源所有者     |      | 是       | 下拉选择 | `iStore.user.userType = 1`                                   |
| 资源编号       |      | 是       | 文本     | 最多 50 字符；允许特殊字符                                   |
| 资源名称       |      | 否       | 文本     | 最大 50 字符                                                 |
| 面积           |      | 是       | 数字     | 单位平方米（㎡）；支持小数点后 2 位                          |
| 位置           |      | 否       | 级联选择 | request接口: 获取位置信息                                    |
| 资源一级分类   |      | 是       | 下拉选择 | request接口: 『资源分类接口占位』,                           |
| 资源二级分类   |      | 否       | 下拉选择 | request接口:『资源二级分类接口占位』,资源一级分类选中后会重新查询资源二级分类 |
| 紧急联系人     |      | 是       | 文本     | 最大20字符                                                   |
| 紧急联系人电话 |      | 是       | 文本     |                                                              |
