## 三、接口信息

### 接口1

- 接口名称: 系统设备列表

- 接口方法及路径: `GET` /xfy/api/data/v2/roomManage/roomDetailSelfAreaSystemDeviceList/:roomId

- 接口传参: 

  - pageNo: number,
  - pageSize: number

- 数据返回格式: 

  ```json
  {
      status: number
      data: {
          "total": 0,
          "alarmTotal": 0,
          "list": [
              {
                  "id": 0,
                  "deviceNo": "string",
                  "deviceType": "string",
                  "systemName": "string",
                  "status": 0
              }
          ]
      },
  	msg: string
  }
  ```

### 接口2

- 接口名称: 资源详情-自管设备列表

- 接口方法及路径: `GET` /xfy/api/data/v2/roomManage/roomDetailSelfAreaDeviceList

- 接口传参: 

  - roomId: number,资源详情的id
  - pageNo: number,
  - pageSize: number

- 数据返回格式: 

  ```json
  {
      status: number,
      data: {
      	items: [
          {
              "id": 0,
              "name": "string",
              "num": 0,
              "belongSystem": "string",
              "deviceTypeName": "string",
              "deviceModel": "string",
              "roomId": 0,
              "roomNo": "string",
              "fpuId": 0,
              "fpuName": "string",
              "deviceNo": "string",
              "maker": "string",
              "productionAt": 0,
              "isNearDue": true,
              "maintenanceCycle": "string",
              "nextMaintenanceAt": 0,
              "accessory": {}
          }
      ],
          total: number
      },
      msg:string
  }
  ```

- 补充说明: 无论成功失败都通过message提示,失败提示逻辑: res.msg|| 默认文本
