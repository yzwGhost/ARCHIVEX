# 莱茵生命本地档案馆

本地静态档案馆。将真实文档放入 `documents/`（支持子目录），即可通过奶油白三维档案阵列浏览、检索、收藏、阅读和下载。场景使用 Three.js 建模与正交斜俯视镜头，支持窄窗口布局。

## 安装与运行

使用 Node.js **22.22.2+（22 系列）、24.15.0+（24 系列）或 26+**，以及 npm：

```sh
npm install
npm run dev
```

打开终端显示的本机地址（通常为 `http://127.0.0.1:5173`）。生产构建及本机预览：

```sh
npm test
npm run build
npm run preview
```

本机开发服务的“上传档案”按钮可选择多份文件，选择已有分类、填写新分类或保留“未分类”。单文件上限为 **50 MiB**；同名文件或会共用同名元数据的文件会提示冲突，不会覆盖。每份文件分别显示结果，成功后页面立即刷新档案。文件保存到 `documents/`，分类写入同名 `.meta.json`，重启或换浏览器后仍可用。也可以继续手动管理 `documents/`。

`npm run preview` 的本机预览服务也支持上传。单独部署 `dist/` 为纯静态站点时只能浏览、筛选和下载，页面不会显示上传入口。`dist/` 包含静态网站、文档原件及生成的预览；请留意其中的文档内容。项目不提供账户、数据库或远程同步功能。

## 删除与回收区

本机开发和预览服务中，档案详情页可将单份档案移入回收区；工具栏的“管理分类”可将一个分类及其中所有档案作为一个批次移入回收区。“未分类”使用“清空未分类”操作。删除成功后档案会播放抽离动画，随后更新阵列；系统设置为减少动态效果时会跳过动画。

“回收区”按批次列出已回收的档案，点击“恢复”会还原到原来的 `documents/` 路径。若原路径已有文件，或共用的 `.meta.json` 内容已改变，恢复会提示冲突并保留回收批次，绝不覆盖现有文件。回收区保存在项目根目录的 `.archive-trash/`，不会自动清空；重启服务时会检查并恢复中断的操作。纯静态部署没有删除和恢复入口。

## 文档与元数据

支持 `.md`、`.docx`、`.pdf` 和 `.doc`：Markdown 与 DOCX 转换为 HTML，PDF 使用 PDF.js 在页面内绘制可滚动的正文画布，旧版 DOC 仅提供下载。所有格式均保留下载原文件入口。中文、空格文件名及不同子目录中的同名文件均可使用。

例如放入 `documents/研究/实验记录.md`，可选配 `documents/研究/实验记录.meta.json`：

```json
{
  "title": "实验记录",
  "summary": "样本观察与实验结论。",
  "date": "2026-10-10",
  "category": "研究"
}
```

四个字段均可省略。默认标题为文件名，日期为最后修改时间；Markdown、DOCX 的摘要取正文开头，PDF、DOC 使用格式提示。日期按实际时间降序排序，建议使用 `YYYY-MM-DD`；同日期按路径排序。无效 JSON 会产生警告并退回默认信息，单份 DOCX 转换失败会保留下载入口。

**手动新增、删除、修改文档或元数据后，必须停止并重新运行 `npm run dev`，或重新执行 `npm run build`。** 网页上传则会即时更新，无需重启。仅刷新页面不会重新扫描手动修改的磁盘内容。`public/archive/` 为自动生成目录，请通过 `documents/` 管理原件。

## 浏览方式与限制

- 同一分类的真实档案排列在同一横排，空白档案填充两侧和远景。左右方向键切换同排档案，上下方向键切换分类排；底部显示当前分类。
- 鼠标移入档案仅显示可点击光标；首次点击选中并抬升，再次点击同一档案才抽取并进入详情。点击其他档案时原档案回落，新档案抬升。`ACCESS FILE` 或画布聚焦时按 Enter 可直接打开当前档案。点击“阅读档案正文”打开实际文档。Esc 逐层返回，正文关闭后恢复阅读按钮焦点。
- `ARCHIVE INDEX` 或 `/` 打开目录，可按编号、标题、摘要检索，并按真实分类筛选。输入时方向键不会移动场景。
- 右上角“分类”按完整档案清单筛选三维阵列和简洁列表；目录和收藏仍可查找全部档案。从目录打开其他分类的档案时，页面会切到该分类并定位原文件，编号保持不变。筛选结果为空时可返回“全部”或上传新档案。
- “收藏档案”将稳定文件 ID 保存在当前浏览器的 localStorage 中；`SAVED` 打开收藏目录。存储不可用时仍可本次会话收藏，并显示提示。更换端口、浏览器或清除网站数据会使用不同收藏存储。
- “360° 检视”支持拖动旋转、滚轮缩放、平滑重置视角；“展开档案结构”与“收合档案结构”展示同一模型的封面、固定件、资料层和背板。
- 开场约 3.6 秒，可跳过；同一会话仅自动播放一次，右上时钟图标可以重播。阵列起伏、抬升、镜头移动、抽取、详情、返回、目录、收藏、旋转和结构拆装均有动画。
- 三维场景需要 WebGL 2；不可用时自动进入真实文件列表，仍支持检索、收藏、正文和下载。窄屏详情区可以滚动。

DOCX 预览以正文阅读为目标，复杂分页、批注、浮动对象及特殊版式可能无法完整还原；需要原版式时请下载并使用 Word 查看。PDF 以页面内画布预览，支持滚动和 Esc 返回；不提供文字选择、搜索或批注，加载失败时可下载原文件。远景无编号档案仅用于延续画面，不计入文档数量。

## 实现结构

`src/archive-state.ts` 维护选择、分组、检索与收藏，`src/scene.ts` 负责界面和键盘操作，`src/scene/ArchiveWorld.ts` 负责渲染与镜头，`ArchiveModel.ts` 定义实体档案和拆解层，`ArchiveMotion.ts` 处理可中途转向的缓动。`src/main.ts` 管理目录请求和阅读器生命周期。三维引擎和 PDF 阅读器按需加载。

场景采用暖白环境反射、柔化投影和低强度接触阴影；`ArchiveContactPass.ts` 排除透明封皮及文字贴层，避免透明区域形成整块遮蔽。`ArchiveWave.ts` 为前景实体和远景阵列提供同一连续波形，进入详情时平滑收敛，选中档案额外抬升。
