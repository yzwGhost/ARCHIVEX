# 莱茵生命本地档案馆

面向桌面浏览器的本地静态档案馆。将真实文档放入 `documents/`（支持子目录），即可通过单列档案序列浏览、阅读和下载。初始目录为空。

## 安装与运行

使用 Node.js **22.22.2+（22 系列）、24.15.0+（24 系列）或 26+**，以及 npm：

```sh
npm install
npm run dev
```

打开终端显示的本机地址（通常为 `http://127.0.0.1:5173`）。生产构建及本机预览：

```sh
npm test
npm run build
npm run preview
```

`dist/` 包含静态网站、文档原件及生成的预览；请留意其中的文档内容。项目不提供账户、上传、服务器 API、数据库或同步功能。

## 文档与元数据

支持 `.md`、`.docx`、`.pdf` 和 `.doc`：Markdown 与 DOCX 转换为 HTML，PDF 使用浏览器内置阅读器，旧版 DOC 仅提供下载。所有格式均保留下载原文件入口。中文、空格文件名及不同子目录中的同名文件均可使用。

例如放入 `documents/研究/实验记录.md`，可选配 `documents/研究/实验记录.meta.json`：

```json
{
  "title": "实验记录",
  "summary": "样本观察与实验结论。",
  "date": "2026-10-10",
  "category": "研究"
}
```

四个字段均可省略。默认标题为文件名，日期为最后修改时间；Markdown、DOCX 的摘要取正文开头，PDF、DOC 使用格式提示。日期按实际时间降序排序，建议使用 `YYYY-MM-DD`；同日期按路径排序。无效 JSON 会产生警告并退回默认信息，单份 DOCX 转换失败会保留下载入口。

**新增、删除、修改文档或元数据后，必须停止并重新运行 `npm run dev`，或重新执行 `npm run build`。** 仅刷新页面不会重新扫描磁盘。`public/archive/` 为自动生成目录，请通过 `documents/` 管理原件。

## 浏览方式与限制

悬停或键盘聚焦档案可查看信息并向上抽出；点击、Enter 或空格打开阅读视图；返回按钮或 Esc 关闭并恢复档案焦点。文档较多时可使用底部横向滚动条或触控板水平滚动。动画按设计始终播放，包括系统启用减少动态效果时。

DOCX 预览以正文阅读为目标，复杂分页、批注、浮动对象及特殊版式可能无法完整还原；需要原版式时请下载并使用 Word 查看。PDF 预览依赖桌面浏览器的内置 PDF 功能；没有该功能时可下载原文件。项目未设计手机布局。
