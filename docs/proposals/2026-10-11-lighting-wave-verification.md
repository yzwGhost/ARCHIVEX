# 柔光与波浪增强验收

## 已实施

- 暖白环境反射、降低曝光和主光强度，象牙白哑光封面与更克制的金属反射。
- VSM 柔化投影与低强度 GTAO 接触阴影；透明封皮、文字贴层不参与不透明遮蔽。
- 前景与远景使用统一空间波形，起伏范围约 0–0.98，主要周期约 8.7 秒；选中额外抬升 1.05。
- 进入详情时波浪平滑归零，保留抽取、收回、旋转和结构拆装动画。

## 验证记录

- `npm test`：31 项通过，覆盖波幅、平滑性、空间连续性及详情收敛。
- `npm run build`：通过，37 份档案构建无内容警告；Vite 仍提示三维引擎分块超过 500 kB。
- 本机浏览器检查：阵列连续起伏、详情抽取、360° 拖动旋转、展开结构、逐层返回，以及首末分组切换。
- 浏览器控制台无警告或错误。代码复查发现的透明物体 VSM/GTAO 遮蔽问题已修复并复查。
- 截图与动态预览位于本机 `.superpowers/lighting-wave/`（忽略提交目录）。动态预览由间隔截图生成，仅用于展示波形，不作为帧率测量。
