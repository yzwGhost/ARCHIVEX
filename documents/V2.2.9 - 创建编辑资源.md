# V2.2.9 - 创建编辑资源

> 仅需填写 UI 与接口信息。L1–L4 的目录组织、Service、业务 Store、页面交互编排和 UI 实现由 Codex 根据项目规范自行拆分与完成。

## 一、基本页面信息

- 页面名称：创建/编辑资源
- 页面路径：`src\app\screens-v2\ziyuanguanli\ResourceSave`
- 样式信息：
  - 使用src\components-v2\Form组件
  - `props.type = create` 时弹窗标题为“新增资源”；`props.type = update` 时弹窗标题为“编辑资源”。
  - 未提供样式设计时，默认遵循项目当前新版组件、布局与视觉规范。

## 二、交互内容

1. 页面底部固定“取消”和“提交”按钮。不随着页面滚动
2. `props.type = create`
   - 页面标题为“新增资源”。
   - 点击提交时调用[新增资源](#接口3)；成功后返回上一级页面，
3. `props.type = update`
   - 页面标题为“编辑资源”。
   - 跳转页面时将数据回填至表单。
   - 点击提交时调用[编辑资源](#接口5)；成功后返回上一级页面，
   - 每次页面销毁时均需清空表单。

## 三、表单信息

### 3.1 表单字段

| 字段名称 | name | 是否必填 | 类型 | 备注 |
| --- | --- | --- | --- | --- |
| 资源所有者 | belongFpuId | 是 | select | 请求[单位列表](#接口2) |
| 资源编号 | roomNo | 是 | text | 最多 50 字符；允许特殊字符 |
| 资源名称 | name | 否 | text | 最多 50 字符 |
| 面积 | buildingArea | 是 | number | 单位平方米（㎡）；支持小数点后 2 位 |
| 位置 | location | 否 | cascader | 请求[获取位置信息](#接口1) |
| 资源一级分类 | sourceType | 是 | select | 请求[资源分类列表](#接口4) |
| 资源二级分类 | businessType | 否 | select | 选中一级分类后以其 `children` 为数据源 |
| 区域类型 | areaType | 是 | select | 选项：`[{ label: '公共区', value: 1 }, { label: '非公共区', value: 2 }, { label: '其他公共区', value: 3 }]` |
| 紧急联系人 | urgentName | 是 | text | 最多 20 字符 |
| 紧急联系人电话 | urgentPhone | 是 | text | |

### 3.2 资源所有者

- 通过[单位列表](#接口2)加载可选单位。
- 接口返回值中 `id` 映射为 `value`，`name` 映射为 `label`。

## 四、接口信息

### 接口1

- 接口名称：获取位置信息
- 关联交互：无
- 请求方式与路径：`GET /xfy/api/data/v2/base/location`
- 请求参数：无
- 返回数据格式：

```json
{
  "status": 0,
  "data": [
    {
      "label": "十一街坊",
      "value": 8,
      "originValue": 8,
      "children": [
        {
          "label": "16号楼",
          "value": "8|8001",
          "originValue": 8001
        }
      ]
    }
  ],
  "msg": ""
}
```

### 接口2

- 接口名称：单位列表
- 关联交互：无
- 请求方式与路径：`POST /xfy/api/data/v2/objects/fpu/query`
- 请求参数：
  - `coql`：`select id, companyName,name from fpu`
  - `fieldApiKeys`：`id, companyName,name`
  - `objectApiKey`：`fpu`
  - `filter`：`{ page: 1, perPage: 10, name: 输入框关键字 }`
- 返回数据格式：

```json
{
  "status": 0,
  "data": {
    "items": [
      {
        "editFlg": 0,
        "name": "测试单位0055666",
        "pId": 525380142829568,
        "id": 527129612455936
      }
    ]
  },
  "msg": ""
}
```

- 字段映射：`id` → `value`，`name` → `label`。

### 接口3

- 接口名称：新增资源
- 关联交互：无
- 请求方式与路径：`GET /xfy/api/data/v2/roomManage/roomCreate`
- 请求参数：表单字段。
- 返回数据格式：

```json
{
  "status": 0,
  "data": {},
  "msg": ""
}
```

- 无论成功或失败，均通过 `message` 提示结果。

### 接口4

- 接口名称：资源分类列表
- 请求方式与路径：`GET /xfy/api/data/v2/roomManage/roomConfigCategoryList`
- 返回数据格式：

```json
{
  "status": 0,
  "data": {
    "items": [
      {
        "name": "string",
        "id": 0,
        "children": [
          {
            "name": "string",
            "id": 0
          }
        ]
      }
    ]
  },
  "msg": ""
}
```

### 接口5

- 接口名称：编辑资源
- 请求方式与路径：`POST /xfy/api/data/v2/roomManage/roomUpdate`
- 请求参数：
  - `id`：number，资源 ID。
  - 表单字段。
- 返回数据格式：

```json
{
  "status": 0,
  "data": {},
  "msg": ""
}
```

- 无论成功或失败，均通过 `message` 提示结果。
