# V2.2.9 消防演练详情（App）

## 1. 需求概述

为 App 新增消防演练只读详情页，供现场用户查看演练的基本信息、图片与附件，以及参与人员和关联资源。

本需求由 Web 端《V2.2.9 消防演练详情》转换而来。移动端采用原生导航、纵向信息卡片和 Tab 分页列表，不使用 Web 的 `ProDescription`、`SuperTable` 或全屏弹窗。

## 2. 页面信息

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 消防演练详情 |
| 页面类型 | 新增只读详情页 |
| 推荐路由 | `/xiaofangyanlian/FpuDrillDetail?id=:id`（待实现） |
| 推荐页面目录 | `src/app/screens-v2/xiaofangyanlian/FpuDrillDetail/`（待实现） |
| 入参 | `id`：消防演练 ID，必填 |
| 页面标题 | 消防演练详情 |
| 参考实现 | App 现有详情页的 `ChannelHeader + ScrollView + Panel + ListV2` 结构 |

### 2.1 页面结构

1. 顶部导航栏：返回按钮与“消防演练详情”标题。
2. 基本信息区：纵向卡片，展示演练字段、图片与附件。
3. 内容 Tab：`参与人员`、`关联资源` 两项；每个 Tab 使用独立的 `ListV2` 分页列表。
4. 本期仅查看，不配置底部操作按钮。

> 页面进入时仅请求详情和必要的枚举映射；切换 Tab 后再按需加载对应列表，避免首次进入同时加载全部分页数据。

## 3. 基本信息

| 字段名称 | 数据字段 | 展示规则 |
| --- | --- | --- |
| 演练时间 | `drillAt` | 毫秒时间戳，格式为 `YYYY-MM-DD HH:mm:ss`；无值显示 `--` |
| 演练科目 | `drillSubject` | 原样展示；无值显示 `--` |
| 演练地点 | `address` | 长文本自动换行；无值显示 `--` |
| 演练类型 | `drillCategory` | 通过“演练类别映射”转换；未映射时展示原始编码或 `--` |
| 演练类别 | `drillType` | 通过“演练类型映射”转换；未映射时展示原始编码或 `--` |
| 演练评估效果 | `resultAssessment` | 通过“演练评估效果映射”转换；未映射时展示原始编码或 `--` |
| 演练图片 | `drillImg` | 多图缩略图网格；点击单图可全屏预览；无图片显示 `暂无图片` |
| 附件 | `accessory` | 文件列表展示文件名与类型；点击进入现有文件预览/下载流程；无附件显示 `暂无附件` |

## 4. 内容 Tab

### 4.1 参与人员

| 项目 | 规则 |
| --- | --- |
| 标题 | 参与人员 |
| 数据来源 | 消防演练人员列表接口 |
| 分页 | 使用 `ListV2` 注入 loader；首屏 `page=1`、`perPage` 使用项目默认分页大小，滚动到底部加载下一页 |
| 列表字段 | 姓名 `name`、联系方式 `phone`、一级单位 `companyName`、二级单位 `fpuName` |
| 筛选 | 由页面筛选入口提交 `name`、`phone`、`companyName`、`fpuName`；筛选变更后从第 1 页重新加载 |
| 空态 | `暂无参与人员` |
| 错误态 | 显示错误文案与“重新加载”入口 |

列表项为只读信息卡片，本期不进入人员详情。

### 4.2 关联资源

| 项目 | 规则 |
| --- | --- |
| 标题 | 关联资源 |
| 数据来源 | 消防演练关联资源列表接口 |
| 分页 | 使用 `ListV2` 注入 loader；首屏 `page=1`、`perPage` 使用项目默认分页大小，滚动到底部加载下一页 |
| 列表字段 | 资源号 `roomNo`、资源名 `roomName`、类型 `useType`、位置 `address` |
| 类型展示 | `useType` 通过“资源类型映射”转换；未映射时展示原始编码或 `--` |
| 筛选 | 由页面筛选入口提交 `roomNo`、`roomName`、`address`、`useType`；筛选变更后从第 1 页重新加载 |
| 空态 | `暂无关联资源` |
| 错误态 | 显示错误文案与“重新加载”入口 |

本期关联资源卡片不跳转资源详情；如后续接入，另行确认目标资源详情路由和权限规则。

## 5. 页面交互与状态

| 场景 | 行为 |
| --- | --- |
| 进入页面 | 校验 `id`；有效时加载详情和 3 个演练字段映射，缺失或非法时显示稳定错误态 |
| 点击返回 | 返回上一页，不修改演练数据 |
| 点击图片 | 调用 App 既有图片预览能力；图片加载失败时显示占位，不影响其他信息 |
| 点击附件 | 调用 App 既有文件预览/下载能力；文件不可访问时提示失败原因 |
| 切换 Tab | 切换内容区域；首次进入目标 Tab 时加载该 Tab 的第一页，已加载的数据保留 |
| 修改筛选 | 重置对应 Tab 的分页并从第一页加载 |
| 详情请求失败 | 显示“加载失败”和“重新加载”入口；不展示上一个演练的旧数据 |
| 枚举映射请求失败 | 不阻断详情展示，相关字段回退原始编码或 `--` |

## 6. 接口与字段处理

> 下表保留原 PRD 的接口契约。App 实现时通过项目统一 `fetch` 基础路径调用，不在 UI 层直接请求接口。

### 6.1 演练类别映射

| 项目 | 说明 |
| --- | --- |
| 接口 | `GET /xfy/api/v2/metadata/drill/fields?field=drillCategory&type=map` |
| 用途 | 将 `drillCategory` 转换为演练类别文案 |

正常返回示例：

```json
{
  "status": 0,
  "data": {
    "1": "综合演练",
    "2": "专项演练",
    "3": "实战演练",
    "4": "桌面演练",
    "5": "无脚本演练"
  },
  "msg": "success"
}
```

### 6.2 演练类型映射

| 项目 | 说明 |
| --- | --- |
| 接口 | `GET /xfy/api/v2/metadata/drill/fields?field=drillType&type=map` |
| 用途 | 将 `drillType` 转换为演练类型文案 |

返回结构同 6.1，字段值以服务端实际配置为准。

### 6.3 演练评估效果映射

| 项目 | 说明 |
| --- | --- |
| 接口 | `GET /xfy/api/v2/metadata/drill/fields?field=resultAssessment&type=map` |
| 用途 | 将 `resultAssessment` 转换为评估效果文案 |

正常返回示例：

```json
{
  "status": 0,
  "data": {
    "1": "达到预期效果",
    "2": "部分环节有待改进",
    "3": "没有达到预期需修改预案",
    "4": "演习失败需重新演练"
  },
  "msg": "success"
}
```

### 6.4 消防演练人员列表

| 项目 | 说明 |
| --- | --- |
| 接口 | `POST /xfy/api/data/v2/drill/userList` |
| 必填参数 | `drillId`：当前页面入参 `id` |
| 分页参数 | `page`、`perPage` |
| 可选筛选参数 | `name`、`companyName`、`fpuName`、`phone` |
| 响应处理 | 读取 `data.items` 和 `data.count`；`items` 缺失或非数组时进入稳定错误态 |

### 6.5 消防演练关联资源列表

| 项目 | 说明 |
| --- | --- |
| 接口 | `POST /xfy/api/data/v2/drill/roomList` |
| 必填参数 | `drillId`：当前页面入参 `id` |
| 分页参数 | `page`、`perPage` |
| 可选筛选参数 | `address`、`roomName`、`roomNo`、`useType` |
| 响应处理 | 读取 `data.items` 和 `data.count`；`items` 缺失或非数组时进入稳定错误态 |

### 6.6 资源类型映射

| 项目 | 说明 |
| --- | --- |

## 7. App 数据分层与行为追踪

### 7.1 数据分层

| 层级 | 职责 |
| --- | --- |
| Adapter | 校验详情、人员列表、资源列表和映射接口的响应；异常时返回含 `apiKey`、字段路径与追踪信息的解析错误 |
| Service | 唯一业务请求入口，向 Store 返回 `Result<T>` |
| Store | 管理详情、映射、两个列表的加载/分页/筛选/错误状态；不直接依赖 UI |
| UI | 只读取 Store 或注入 `ListV2` loader，不直接调用 `fetch` 或解析接口数据 |

### 7.2 主流程埋点

| 场景 | trackTarget | trackExtra |
| --- | --- | --- |
| 打开图片预览 | `xiaofangyanlian.detail.image.preview` | `id`、图片索引 |
| 打开附件 | `xiaofangyanlian.detail.attachment.open` | `id`、附件名 |
| 切换内容 Tab | `xiaofangyanlian.detail.tab.switch` | `id`、tab |
| 筛选参与人员 | `xiaofangyanlian.detail.participant.filter` | `id` |
| 筛选关联资源 | `xiaofangyanlian.detail.room.filter` | `id` |
| 重试详情加载 | `xiaofangyanlian.detail.retry` | `id` |
| 重试参与人员加载 | `xiaofangyanlian.detail.participant.retry` | `id` |
| 重试关联资源加载 | `xiaofangyanlian.detail.room.retry` | `id` |

## 8. 非目标

- 不新增演练创建、编辑、删除、审批、签到或评价操作。
- 不修改演练详情、人员、关联资源与元数据接口的后端契约。
- 不新增人员详情或资源详情跳转。
- 不调整 Web 端页面、表格或筛选逻辑。

## 9. 验收标准

1. 通过有效 `id` 可进入详情页并展示基本信息；无效 ID 或详情请求失败时有稳定错误态和重试入口。
2. 演练类别、类型、评估效果与资源类型可正确映射；映射接口失败不影响主体信息和列表展示。
3. `drillImg` 的多图、空图和图片加载失败均不会造成白屏；有图片时可预览。
4. `accessory` 能展示文件名，点击后进入 App 的既有文件预览/下载流程；无附件或文件不可访问有明确反馈。
5. 参与人员与关联资源可独立分页、筛选、加载更多、显示空态和错误重试。
6. 切换 Tab 不重复请求已加载的第一页；修改筛选条件后仅重置目标列表。
7. 新增的主动点击入口均使用 `BehaviorTouchable` 或带 `trackTarget` 的 `Button`，且不把动态 ID 拼入 `trackTarget`。

## 10. 待确认项

1. 路由是否采用本文建议的 `/xiaofangyanlian/FpuDrillDetail`，以及该页面应归属的菜单/频道配置。
2. 原 PRD 中 `drillCategory`、`drillType` 的中文名称与映射字段语义是否最终确认；当前按原字段表保留。
3. 资源列表筛选参数以 `useType` 为准；原始字段表中的 `userType` 视为笔误，待后端契约确认。
4. 附件预览是否统一复用 App 现有组件，或仅提供下载；图片预览组件的具体实现待开发阶段确认。
5. 人员和关联资源的默认 `perPage` 值及筛选入口形态（页头筛选/独立搜索页）待 UI 评审确认。
