# V2.2.9 资源管理Tab1 - 资源台账

> `appStore.userStore.userType !== 1` 代表系统端,如果 userType == 1 菜单上不显示该页面入口

## 一、基本页面信息

- 页面名称: 资源台账
- 页面路径: src\app\screens-v2\ziyuanguanli\ResourceList
- 样式信息: 
  - 页面上半部分为统计卡片(5项):
    - 总资源数
    - 空置资源数
    - 已承租
    - 即将到期
    - 已到期
  - 页面下半部分为列表
  - 统计部分和列表占比为1: 3
  - 页面右下角有添加的悬浮按钮
  - 设计问我意见
  - 可以向我提供设计图
  - 若未提供样式设计：默认遵循项目当前新版组件、布局与视觉规范。

## 二、交互信息

1. 列表卡片可点击,点击后跳转页面暂定
2. 添加按钮跳转页面暂定

## 接口信息

### 接口1

- 接口名称: 位置信息选项

- 接口方法及路径: `GET` /xfy/api/data/v2/base/location

- 数据返回格式: 

  ```json
  {
      status: number,
      data: [
          	{
      			"label": "十一街坊",
      			"value": 8,
      			"originValue": 8,
      			"children": [
      						{
      	            			"label": "16号楼",
                                  "value": "8|8001",
      							"originValue": 8001
      						}
      					]
      			}
      	],
      msg: string
  }
  ```

## 接口2

- 接口名称: 资源分类选项

- 接口方法及路径: `GET` /xfy/api/data/v2/roomManage/roomConfigCategoryList

- 数据返回格式：

  ```json
  {
      status: number,
      data: {
          items: [
          		{
              		"name": "string",
              		"id": 0,
              		"children": [
                  	{
                      	"name": "string",
                      	"id": 0
                  	}
              	]
          	}
      	]
      },
      msg: string
  }
  ```

### 接口3

- 接口名称: 查询资源台账

- 接口方法及路径: `POST` /xfy/api/data/v2/roomManage/roomQuery

- 接口传参: 

  - pageNo: number
  - pageSize: number
  - 列表筛选字段

- 数据返回格式:

  ```json
  {
      status: number,
      data: {
          items: [
              {
              "id": 0,
              "roomNo": "string",
              "name": "string",
              "buildingArea": 0,
              "sourceType": 0,
              "businessType": 0,
              "belongFpuId": 0,
              "belongFpuName": "string",
              "useFpuId": 0,
              "useFpuName": "string",
              "usageMode": 0,
              "usageModeName": "string",
              "leaseStatus": 0,
              "leaseStatusName": "string",
              "building": "string",
              "floor": "string",
              "area": "string",
              "urgentName": "string",
              "urgentPhone": "string",
              "fpuId": 0,
              "fpuName": "string",
              "rentStartAt": 0,
              "rentEndAt": 0,
              "cfrOwner": "string",
              "cfrManager": "string",
              "fpuNature": 0
          }
          ],
          total: number
      }
  }
  ```

### 接口4

- 接口名称: 资源统计

- 接口方法及路径: `GET` /xfy/api/data/v2/roomManage/roomStat

- 数据返回格式: 

  ```json
  {
      status: number;
      data: {
          "total": 0, // 总资源数
          "idle": 0, // 空置资源数
          "leased": 0, // 已承租数
          "pendingLeave": 0, // 退租待生效数
          "nearExpire": 0, // 即将到期
          "expired": 0 // 已到期
      },
  	msg: string
  }
  ```
