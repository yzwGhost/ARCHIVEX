# V2.2.9 资源详情Tab1- 首页

## 一、基本页面信息

- 页面路径: src\app\screens-v2\ziyuanguanli\ResourceDetail\Pages\Home

- 样式信息: 

  - 分为4个模块

    - 基本信息

      - 使用src\components-v2\Property

      - 渲染信息

        | 字段名称                         | dataIndex    | 字段类型(valueType) | 备注                                                         |
        | -------------------------------- | ------------ | ------------------- | ------------------------------------------------------------ |
        | 资源编号                         | roomNo       | text                |                                                              |
        | 资源名称                         | name         | text                |                                                              |
        | 面积                             | buildingArea | text                |                                                              |
        | 位置                             |              | text                | 使用『[位置信息](#接口1)』的 返回值进行映射,映射的格式为building - building\|floor - building\|floor\|area |
        | 区域类型                         | areaType     | select              | 数据源: [{label: 公共区,value:1},{label:非公共区,value:2},{label:其他公共区,value:3}] |
        | 资源一级分类                     | sourceType   | select              | ProDescription.Item.request中调用接口:『[资源分类](#接口2)』 |
        | 资源二级分类                     | businessType | select              | 通过sourceType找到一级分类后在其children中匹配               |
        | 资源照片(取自最近一次专项检查单) | photos       | file                | 使用antd Image进行渲染,多张照片                              |

        

    - 承租信息

      - 使用src\components-v2\Property

      - 渲染信息

        | 字段名称           | dataIndex       | 字段类型(valueType) | 备注                                                         |
        | ------------------ | --------------- | ------------------- | ------------------------------------------------------------ |
        | 承租方             | fpuName         | text                |                                                              |
        | 实际使用方         | useFpuName      | text                |                                                              |
        | usageMode          | 使用方式        | select              | ProDescription.Item.request中调用接口:『[使用方式](#接口3)』 |
        | 承租起止           |                 |                     | 使用dayjs渲染,格式为rentAt~rentEndAt,时间渲染格式为:YYYY年MM月DD日 |
        | 消防安全责任人     | cfrOwner        | text                |                                                              |
        | 消防安全责任人电话 | cfrOwnerPhone   | text                |                                                              |
        | 消防安全管理人     | cfrManager      | text                |                                                              |
        | 消防安全管理人电话 | cfrManagerPhone | text                |                                                              |

        

    - 资源内人员

      - 列表

      - 不用显示分页

      - 列表字段

        | 字段名称 | dataIndex  | 备注         |
        | -------- | ---------- | ------------ |
        | 人员名称 | personName |              |
        | 联系方式 | phone      |              |
        | 所在单位 | unitName   |              |
        | 操作     |            | 查看详情按钮 |

        

    - 大功率电器

      - 上半部分为统计卡片

        - 总数- totalCount
        - 总功率: 单位为kw
        - 使用中

      - 下半部分为列表

        - 需要分页

        - 列表字段

          | 字段名称     | dataIndex  | 备注         |
          | ------------ | ---------- | ------------ |
          | 编号         | deviceName |              |
          | 名称         | name       |              |
          | 额定功率(kw) | power      |              |
          | 使用单位     | fpuName    |              |
          | 操作         |            | 查看详情按钮 |

## 三、 接口信息

### 接口1

- 接口名称: 位置信息

- 接口方法及路径: `GET` /xfy/api/data/v2/base/location

- 数据返回格式: 

  ```json
  {
      status： number,
      data: [
      	{
      "label": "十一街坊",
      "value": 8,
      "originValue": 8,
      "children": [
          {
              "label": "16号楼",
              "value": "8|8001",
              "originValue": 8001
          }
      ]
  }
      ],
  	msg: string
  }
  ```

### 接口2

- 接口名称: 资源分类

- 接口方法及路径: `GET` /xfy/api/data/v2/roomManage/roomConfigCategoryList

- 数据返回格式: 

  ```json
  {
      status: number,
      data: {
          items: [
          {
              "name": "string",
              "id": 0,
              "children": [
                  {
                      "name": "string",
                      "id": 0
                  }
              ]
          }
      ]
      },
      msg: string
  }
  ```
